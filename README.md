# Using-Access-Control-Lists-to-Modify-File-System-Permissions-on-Windows-Systems-Lab
This lab report documents the implementation and validation of Windows Access Control Lists (ACLs) to manage file system permissions. It demonstrates configuring Access Control Entries (ACEs) using both the Windows Explorer GUI and the icacls.exe command-line utility across departmental directories (SFfiles, HRfiles, MGRfiles). Additionally, it covers automating identity management and permission inheritance via PowerShell scripts, verifying permission enforcement, and analyzing the Principle of Least Privilege in enterprise security architectures.
